01 RESEARCH NOTE

When does a color become the car's?颜色，究竟属于谁？

A diffusion model can draw every requested object and color, then assign the colors to the wrong objects. Counterfactual prompt switches offer a way to study when that assignment changes.扩散模型可能画对对象和颜色，却配错归属。反事实提示词切换提供了研究归属何时还能改变的方法。

02 RESEARCH NOTE

A vector is not yet a token向量进了模型，不代表模型读懂了

Projecting fixed multimodal features to the right hidden size solves a wiring problem. Readability needs an interface—and controls that show what the backbone actually contributes.把固定多模态特征投影到正确维度，只解决了接线问题。可读性需要更好的接口，也需要辨明骨干贡献的对照实验。

03 RESEARCH NOTE

A hard question is not necessarily a hard search难题，不一定需要难搜索

Multi-hop questions can be solved with one search. What matters for agent training is the path a model must take to find the evidence.多跳问题也可能一次检索就得到答案。训练搜索智能体时，更重要的是模型找到证据的路径。

04 RESEARCH NOTE

A search agent needs a ledger, not a longer transcript搜索智能体需要一本账，而非更长的对话

A persistent record of evidence, candidates, and missing constraints helps the agent carry useful state through a long run.持久记录证据、候选与缺失约束，才能让智能体在长程任务里带着有效状态前进。
