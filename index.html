ACTS

Design the path to evidence before writing the question, so search agents learn step-by-step evidence gathering rather than one-shot answers.先设计证据如何被发现，再生成问题，让搜索智能体学会逐步取证，而不是一次检索就作答。
SOURCE → STATE → FINAL
arXiv · ICLR 2027 under reviewarXiv

ClueFlow

Attributed research-state transitions guide both SFT and turn-level PPO for long-horizon search.以可归因的研究状态转移同时指导 SFT 与逐轮 PPO，学习长程搜索。
COMPETENCE ROUTING
ICLR 2027 · Under reviewCo-first author共同第一作者

CATER

Route each problem by the student's current competence: RL where it is uncertain, concise self-distillation where it is reliable.按学生当前能力分配训练：不稳定时用强化学习，稳定后用简洁自蒸馏压缩推理。
TEACHER ⟂ VERIFIER
ICLR 2027 · Under reviewFirst author第一作者

SP-OPD

KL-project the teacher so on-policy distillation stops suppressing verifier-accepted tokens.用 KL 投影修正教师分布，让在线蒸馏不再压低通过验证的正确轨迹。
WHEN DOES BINDING SET?
ICLR 2027 · Under reviewFirst author第一作者

CrystalBind

Diagnose when attribute binding crystallizes during denoising, then guide it at inference time without new weights.诊断属性绑定在去噪中何时定型，并在推理时引导，无需训练新权重。
